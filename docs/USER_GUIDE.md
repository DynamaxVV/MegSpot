# 用户指南

本文档说明当前二次开发版的实际使用方式。当前版本为 <code>2.2.12-vv1.0.6</code>。

## 1. 快速开始

1. 启动 MegSpot，默认进入首页。
2. 需要逐组核对两套图片时，使用首页的左右两栏成对图片流程。
3. 只需要从文件列表中挑选若干图片时，进入传统的图片文件选择流程。
4. 第一次运行建议打开“设置 → 快捷键”，确认快捷键没有与系统或其他软件冲突。

应用不要求登录，普通对比过程只读取本地文件。偏好、最近打开的文件夹等少量状态会保存在本机；每次启动都会回到空白首页，不恢复上一次成对对比任务。

当前公开版本聚焦本地图片对比。视频、图像快照（<code>.mgt</code>）、GIF 导出、HEVC/H.265 播放、Linux 命令行启动和多语言界面尚未启用，本文不提供这些流程的使用说明。

## 2. 成对图片对比

### 2.1 添加来源

在首页左右两侧分别添加图片或文件夹。每一侧可以添加多个来源，并可在同侧拖拽调整文件夹顺序。

- 文件夹只读取直属子文件中的支持图片，不递归扫描子目录。
- 支持的常见格式包括 JPEG、PNG、BMP、TIFF、SVG、ICO、AVIF 等，最终能否解码还取决于 Electron/Chromium。
- 同一路径只保留一次；路径按绝对路径去重。
- 两侧都准备好后，首页会显示配对预览。确认后进入 <code>/image/compare?pairTask=1</code> 工作区。

### 2.2 配对规则

MegSpot 按以下顺序建立对比组：

1. 先按文件名去掉扩展名后进行匹配，并忽略大小写。
2. 文件名末尾的“拷贝”会按同一逻辑名称处理，适合处理系统生成的复制文件名。
3. 形如 <code>1+2+3</code> 的组合文件名会尝试与其中的单个逻辑名称匹配；存在歧义时采用保守的排序顺序。
4. 仍未匹配的图片按两侧各自的排序结果依次配对，数量多的一侧保留单边图片。
5. 同一来源内按名称、修改时间或文件大小排序；升序/降序均可。最终对比组顺序以左侧为主。

多文件夹来源会按来源顺序分别建立配对范围，避免同侧不同来源中的文件被意外跨文件夹配对。

### 2.3 工作区

工作区提供三种模式：

- **并排**：左右画布同时显示，适合持续观察差异。
- **单页**：当前画布占满工作区，使用左右方向键临时查看另一侧。
- **分割**：在同一画布区域中分割显示两侧内容。

常用行为：

- 上方向键切换上一组，下方向键切换下一组。
- 按住左方向键可临时在左侧查看右图；按住右方向键可临时在右侧查看左图，松开恢复。
- 双击某一张图可选中单图，之后的缩放、旋转等操作只作用于选中的图。
- 空格键将当前对比组恢复到初始位置。
- 可在工具栏切换普通显示与原图/高清显示模式。
- 亮度、对比度、饱和度、灰度、Gamma、色阶、RGB 取色器和直方图等工具作用于当前工作区。

### 2.4 文件变更与刷新

- 当前图片内容被修改时，画面会尝试重新加载。
- 文件新增、删除或重命名会使当前任务进入需要刷新的状态。
- 选择“刷新配对”后才会重新建立队列；这一步是有意设计的，用于避免比较过程中静默改变顺序。
- 如果对比组缺少某一侧图片，工作区可按当前实现临时显示前一组同侧图片；这不是新的配对关系，刷新任务后仍以实际文件为准。

## 3. 审校/标注模式

成对图片工作区支持从图源文件夹读取一个 TXT 标注文件。标注文件应放在图片所在文件夹中；当前版本只接受解析出的有效文件，并将对应图片的标注显示在审校面板和画布上。

### 3.1 文件格式

每个图片段落以图片文件名开始，每条标注包含序号、归一化坐标和文本：

~~~text
>>>>>>>>[059.jpeg]<<<<<<<<
----------------[1]----------------[0.858,0.108,1]
这里是需要在该位置复核的文本。
----------------[2]----------------[0.420,0.680,2]
另一条标注。
~~~

规则：

- 图片名写在 <code>&gt;&gt;&gt;&gt;&gt;&gt;&gt;&gt;[图片名]&lt;&lt;&lt;&lt;&lt;&lt;&lt;&lt;</code> 中。
- 标注序号必须是数字。
- 坐标是 <code>x,y,type</code>，<code>x</code> 和 <code>y</code> 的范围都是 0 到 1，表示相对于图片宽高的归一化位置。
- <code>type</code> 当前支持 <code>1</code> 和 <code>2</code>，用于区分应用中的标注类型。
- 标注文本为空或坐标不合法时会被忽略。
- 文件名比较忽略路径、扩展名大小写规则按当前解析器处理；标注必须对应当前图源文件夹中的图片。

### 3.2 操作

- 使用审校按钮或 <code>Ctrl/Command + R</code> 打开/关闭审校模式。
- 使用 <code>Ctrl/Command + N</code> 显示/隐藏画布中的标注序号。
- 审校面板可展开、收起和调整宽度。
- TXT 文件发生变化后，重新加载来源或刷新配对以重新读取内容。

## 4. 传统图片流程

### 图片

1. 从首页进入图片对比。
2. 在文件选择页使用左侧文件夹树定位目录，在右侧文件列表选择图片。
3. 通过“已选”文件长廊查看、删除或拖拽调整顺序。
4. 进入图片对比页，使用工具栏进行布局、滤镜、缩放、取色和直方图操作。

## 5. 当前未启用的功能

以下能力可能仍能在上游代码或依赖中找到相关痕迹，但不属于当前公开安装包的可用范围：

- 图像快照（<code>.mgt</code>）和 GIF 导出。
- 视频预览、视频截屏对比和帧同步。
- HEVC/H.265 播放支持。
- Linux 命令行启动参数。
- 多语言界面。

## 6. 默认快捷键

快捷键可以在“设置 → 快捷键”中修改或恢复默认值。macOS 使用 Command，Windows/Linux 使用 Control；表中的“Ctrl/Command”表示这一差异。

| 操作 | 默认快捷键 |
| --- | --- |
| 返回文件选择 | Esc |
| 画布向上/左/下/右移动 | W / A / S / D |
| RGB 取色器 | Ctrl/Command + P |
| 上一组/下一组 | ↑ / ↓ |
| 临时查看另一侧 | ← / →（按住） |
| 当前组回正 | Space |
| 审校模式开关 | Ctrl/Command + R |
| 审校标注序号 | Ctrl/Command + N |

如果修改后的按键没有生效，先保存设置，再重新进入图片对比工作区；同一组合键不应同时绑定多个动作。

## 7. 诊断日志

遇到白屏、图片加载失败、快速翻页异常或渲染错误时，可打开“设置/偏好 → 日志”：

- 页面显示当前日志文件位置和最近 100 行。
- “刷新”重新读取当前日志。
- “打开日志文件夹”可在系统文件管理器中定位日志。
- 成对对比相关记录包含操作关联 ID、任务版本、对比组索引、左右侧和经过清理的路径信息，便于把用户操作、状态变化、图片加载和渲染错误串起来。
- 日志会限制路径和错误文本的长度；提交前请检查是否包含不希望公开的本地文件名。

反馈问题时请附上复现步骤、系统版本、MegSpot 版本、涉及图片类型以及相关日志片段。不要上传原始图片，除非你确认图片可以公开。
